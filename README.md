### Featured Projects & Products
- **[Kairo Technologies](https://thekairo.tech)**: Maker of **[Kairo Cloud OS](https://thekairo.dev)** (distributed PTY terminal, code editor, persistent workspaces on Docker/K8s/GPUs), **[Kairo Orbit](https://orbit.thekairo.dev)** (run Mac remotely from iPhone/Android via AI operator), and **[PAIR](https://pair.thekairo.dev)** (pet matchmaking).
- **[StakeUp](https://github.com/SaiDheeraj-19/StakeUp)**: 🏆 **1st Place at Syntax2Code Hackathon** — 24-hour AI accountability app powered by Groq Vision and Llama 3.2 90B Vision with task checks, AI planner, and escrow wallet.

- **[Sonic Bridge](https://github.com/SaiDheeraj-19/SonicBridge)**: Live audio translation over WebSockets streaming 1-to-many in under 6 seconds with noise suppression and VAD.

### Open Source Contributions
- **[vLLM](https://github.com/vllm-project/vllm)**: High-throughput LLM serving engine. Optimized collectives in Tensor Parallel Mixture-of-Experts (MoE) cases using `torch.compile` (PR [#54611](https://github.com/vllm-project/vllm/pull/54611)); fixed KV cache group sizing logic for arbitrary hybrid models (PR [#54613](https://github.com/vllm-project/vllm/pull/54613)).
- **[Laya AI](https://github.com/Laya-AI/Laya)**: Non-autoregressive LLM decision-routing engine. Authored per-language temperature calibration at the logit-scaling step to fix non-English routing (PR [#127](https://github.com/Laya-AI/Laya/pull/127)) and Chinese eval harness (PR [#124](https://github.com/Laya-AI/Laya/pull/124)); architected FastAPI server, CLI concurrent request engine, and CI pipelines (PRs [#125](https://github.com/Laya-AI/Laya/pull/125), [#119](https://github.com/Laya-AI/Laya/pull/119), [#114](https://github.com/Laya-AI/Laya/pull/114)).

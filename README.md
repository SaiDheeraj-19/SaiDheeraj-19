### Featured Systems

  - **[Cloud OS](https://thekairo.dev)**: Distributed web IDE with PTY terminals, persistent workspaces, and remote GPU orchestration on Kubernetes.
  - **[Orbit](https://orbit.thekairo.dev)**: Autonomous AI operator enabling remote macOS execution directly from iOS and Android.
  - **[PAIR](https://pair.thekairo.dev)**: Intelligent pet matchmaking platform.
- **[StakeUp](https://github.com/SaiDheeraj-19/StakeUp)** — 24-hour AI accountability app powered by Groq Vision and Llama 3.2 90B Vision with automated proof verification and escrow staking *(1st Place, Syntax2Code Hackathon)*.

### Open Source

- **[vLLM](https://github.com/vllm-project/vllm)** — High-throughput LLM serving engine:
  - Optimized Tensor Parallel Mixture-of-Experts (MoE) collectives with `torch.compile` ([#54611](https://github.com/vllm-project/vllm/pull/54611)).
  - Fixed KV cache group sizing logic for arbitrary hybrid architectures ([#54613](https://github.com/vllm-project/vllm/pull/54613)).
- **[Laya AI](https://github.com/Laya-AI/Laya)** — Non-autoregressive LLM decision-routing engine:
  - Authored per-language temperature calibration at logit scaling ([#127](https://github.com/Laya-AI/Laya/pull/127)) and Chinese eval harness ([#124](https://github.com/Laya-AI/Laya/pull/124)).
